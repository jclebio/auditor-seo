# Como dominar a automação com Python no Linux

Automatizar tarefas repetitivas economiza horas de trabalho. Quando usamos Python no Linux, temos acesso direto ao sistema de arquivos e processos sem precisar instalar nada extra.

![Terminal do Fedora executando script Python](imagens/terminal-fedora.png)

## Por que escolher Python no Linux para seus scripts?

A linguagem já vem instalada por padrão no Fedora e em quase todas as distribuições modernas. Você pode consultar a [documentação oficial do Python](https://docs.python.org/pt-br/3/) ou ler nosso [guia de comandos básicos no terminal](/guia-terminal-linux) para começar.

![](imagens/diagrama-sem-alt.png)

## Primeiros passos com o módulo pathlib

Veja um exemplo de código que não deve ter seu comentário confundido com um título H1:

~~~python
# Este comentário dentro do bloco de código é ignorado pelo contador de H1
from pathlib import Path
print(Path.cwd())
~~~
